Kennt ihr das?

Die meisten Vereine bewirtschaften ihre Feste mit einem dieser drei Ansätze — und stoßen dabei immer wieder an dieselben Grenzen.

📝

Stift & Papier

Unleserliche Handschrift, verlorene Bonblöcke, keine Echtzeit-Übersicht. Am Ende sitzt ihr stundenlang zusammen, um die Abrechnung hinzubekommen.

📊

Excel-Tabelle

Nicht echtzeitfähig, kein Mehrbenutzerbetrieb, keine Tisch-Zuordnung. Einer tippt, alle anderen warten.

💸

Kommerzielles POS

30–100 € pro Monat plus Hardware. Für 2–3 Feste im Jahr völlig überdimensioniert — und viel zu teuer.

jotti löst genau diese Probleme.

  • Kostenlos — keine Lizenzgebühren, kein Abo, keine versteckten Kosten
  • Keine Hardware — jedes Smartphone wird zur Kasse (BYOD)
  • Einfach — nur die Features, die ein Vereinsfest wirklich braucht
  • Eigener Server — volle Datenkontrolle, keine fremde Cloud
  • Transparente Abrechnung — Echtzeit-Saldo pro Tisch, lückenlose Bestellhistorie

Alles, was euer Vereinsfest braucht.

Nicht mehr, nicht weniger. jotti konzentriert sich auf die Kernfunktionen — damit sich euer Team auf die Gäste konzentrieren kann.

📱

Bestellungen aufnehmen

Produkte und Varianten auswählen, Menge und Kommentare angeben, auf den Tisch buchen — alles im Browser.

🚚

Ausgabe bestätigen

Bestellte Positionen als ausgegeben markieren. Jeder weiß, was raus ist und was noch fehlt.

💰

Kassieren

Am Tisch kassieren — Teilzahlungen möglich. Offener Saldo immer im Blick.

↩️

Stornieren

Falschbestellungen rückgängig machen. Nur Serviceleitung und Admin — mit Pflichtkommentar für volle Nachvollziehbarkeit.

📋

Tischübersicht

Alle Tische mit Status und offenem Betrag auf einen Blick. Sofort den richtigen Tisch finden.

📊

Abrechnung

Tagesabrechnung, pro Tisch und pro Servicekraft. Kein Rätselraten am Ende des Abends.

🖥️

Küchendisplay (KDS)

Eingehende Bestellungen in Echtzeit auf einem Bildschirm in der Küche oder an der Ausgabe.

🖨️

Bon-Druck

Bestellbons automatisch an ESC/POS-Bondrucker senden — Küche und Theke getrennt.

🔐

Rollen & Rechte

Drei Rollen: Admin, Serviceleitung, Servicekraft. Jeder sieht und darf nur, was er braucht.

In drei Schritten startklar.

Keine wochenlange Einrichtung. Kein Schulungsbedarf. Einfach loslegen.

1

Admin richtet ein

Produkte mit Varianten und Preisen anlegen, Tische erstellen, Benutzer einladen — alles über den Admin-Bereich.

2

Team meldet sich an

Jeder Helfer öffnet den Browser auf dem eigenen Smartphone, gibt das Einmalpasswort ein und setzt ein eigenes Passwort.

3

Loslegen

Bestellungen aufnehmen, Ausgabe bestätigen, kassieren, Saldo prüfen — alles vom Smartphone.

Für wen ist jotti gedacht?

jotti ist für alle gemeinnützigen Organisationen, die temporäre Gastronomie-Veranstaltungen durchführen.

Vereine (e.V.)

Sportvereine, Musikvereine, Schützenvereine, Karnevalsvereine, Fördervereine — jeder eingetragene Verein, der Feste veranstaltet.

Gemeinnützige Organisationen

gGmbH, gUG, Stiftungen, kirchliche Träger, NGOs — alle, die unter das Gemeinnützigkeitsrecht fallen.

Typische Veranstaltungen

Vereinsfeste Sommerfeste Weihnachtsmärkte Maihocks Straßenfeste Konzerte Sportevents Fasching Jubiläen Kulturveranstaltungen

Euer Vereinsfest. Eure Daten.

jotti speichert jede Bestellung, jede Zahlung und jede Stornierung als unveränderliches Event. Nachträgliche Manipulation ist technisch ausgeschlossen. Das schafft Vertrauen — gegenüber dem Vorstand, den Helfern und dem Finanzamt.

  • Event-Sourcing — lückenlose, unveränderbare Bestellhistorie
  • Rollenmodell — Admin, Serviceleitung, Servicekraft mit abgestuften Rechten
  • Self-hosted — Daten auf eurem eigenen Server, keine fremde Cloud
  • HTTPS — verschlüsselte Kommunikation per Let's Encrypt

Einzige Kosten: Hosting-Infrastruktur für euren Server — unabhängig von jotti.

🖥️ VPS ab ~3 €/Monat (z.B. Hetzner, Netcup) 🍓 Raspberry Pi ~50 € einmalig 🏢 Vereinseigener Server — 0 €

Für IT-Verantwortliche.

jotti ist self-hosted per Docker Compose. Wer Docker starten kann, kann jotti betreiben.

Tech-Stack

Frontend React, TypeScript, Tailwind CSS
Backend Go, stdlib net/http, pgx
Datenbank PostgreSQL
Infrastruktur Docker Compose, nginx, Let's Encrypt

Anforderungen

Server 1 vCPU, 1 GB RAM, 10 GB SSD
OS Linux (Ubuntu, Debian o.ä.)
Software Docker + Docker Compose
Netzwerk Domain + Port 80/443 offen

Schnellstart

cp .env.example .env    # Konfiguration anpassen
make prod-init          # SSL-Zertifikat erstellen
make prod-up            # Starten

Architektur-Highlights

  • Event-Sourcing für den Kassenbetrieb — lückenlose, unveränderliche Bestellhistorie
  • CRUD für Stammdaten — einfache Verwaltung von Produkten, Tischen, Benutzern
  • JWT-Authentifizierung — sichere, tokenbasierte Anmeldung mit Argon2id-Hashing
  • Mobile-first — optimiert für Smartphone-Browser, Touch-Bedienung
  • AGPL-3.0 — quelloffen, Quellcode auf GitHub einsehbar
